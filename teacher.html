What is kept, and for how long
  • Nicknames, progress and attempts are kept until the class ends (its end date) or is deleted. A student can delete all their own progress from the landing page; you can delete a single student or the whole class here.
  • Program code and output from failed attempts are kept in full for 30 days, then cleared every night. The failure category, misconception matches and a fingerprint of the code stay.
  • Login codes are kept encrypted until the class is deleted or ends. Only you can reveal them (with "Show codes"), and each reveal is logged.
  • PINs are stored only as a one-way hash. No one can see them, not even you.
  • The data is held by Supabase in the EU (Ireland).

Overview

Students

One row per student, one column per unit. Each cell shows the current level, the placement result, ★ Complete once a level 10 task is passed, and flags for the "This is too easy" and "This is way too hard" buttons and for ⚠ 2+ fails in a row.

Select a column heading to sort. Select it again to reverse the order. Unit columns sort by level.

Reset placement

The student takes the placement test once more, with different tasks, the next time they open the unit. Their other progress is kept. The reset is logged.
