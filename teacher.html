    What is kept, and for how long
    • Nicknames, progress and attempts are kept until the class ends (its end date) or is deleted. A student can delete all their own progress from the landing page; you can delete a single student or the whole class here.
    • Program code and output from failed attempts are kept in full for 30 days, then cleared every night. The failure category, misconception matches and a fingerprint of the code stay.
    • Login codes are kept encrypted until the class is deleted or ends. Only you can reveal them (with "Show codes"), and each reveal is logged.
    • PINs are stored only as a one-way hash. No one can see them, not even you.
    • The data is held by Supabase in the EU (Ireland).

    Students

    Class code

    Colour key: grey: Placement to do. Placed but not secured yet, the level: Level 1–3 Level 4–6 Level 7–9 Level 10. Secured, how fresh it is: 100% Secured 90% Fresh 80% Fading 50–70% Revisit soon.

    More about the colours

    A secured unit never falls below 50%, so it is never red. An average of several units can fall between these bands, and takes the band below it. A unit stays grey until the student has done its placement test. A placed unit that isn't secured yet shows its level in that level's colour, never 0%. A student's average is of their secured units; the summary tiles count each student once, by that average or, with nothing secured yet, by their average level. A unit is secured after two level 10 passes with no hints (a pass after "Show me how" doesn't count). It stays at 100% for a week after the last level 10 pass, then drops 10 points for each full week (90%, 80%, 70%, 60%), never below its floor, and one more level 10 pass with no hints brings it back to 100%. The floor is 50% at first and 10 points higher after each return to 100%, so after five returns it is 100% and the unit stays secured.

    Secured score per unit

    Two rows per student, one column per unit. The units are in blocks, one per group (A-level too). Select a block's heading to close or open it; this browser remembers which you closed. Averages and the tiles count only the units for the class's stage; other units still show as columns. Select a column heading to sort. Select it again to reverse the order. Unit columns sort by secured score, and every table follows the same order. Select a name to open that student. The Freshness row shows the secured score and its label (or Not secured yet). The Level row shows the level (in its colour while the unit isn't secured yet), the placement result, ★ Complete once a level 10 task is passed, and these flags, with the time of the newest press:

    • Too easy the student pressed "This is too easy" in this unit, which moved them up one level: check that their level is right
    • Way too hard the student pressed "This is way too hard" in this unit, which moved them down one level: check that their level is right
    • Paste flagged in a task in this unit (with the count if there are several). A paste is flagged when the editor is empty and the paste is 3 lines or more, or when a single paste is more than 8 lines. Select the flag to see when, which task, and the code of their next check on it.

    Leaderboards

    Each unit gives up to 300 points: up to 200 for its secured score and up to 100 for its level. Most improved is the points gained in the last 14 days.

    How it works

    Every unit counts, whatever the class's stage. Secured points: up to 200, 2 for each percent of a secured unit's score (100% gives 200, 50% gives 100; a unit that isn't secured gives 0). Level points: up to 100, 10 for each level of a placed unit (level 10 gives 100; a unit not started, or with its placement to do, gives 0). Most improved is the points gained in the last 14 days: today's total minus the total 14 days ago, worked out from the saved attempts and level changes. Students with the same points share a place. Students see their own class's boards, with nicknames only.

    Two more totals come on top of the 300 a unit (prompt 23). Programme points: each level 10 writing task (write, or write from scratch) a student passes in endless mode gives 50 points the first time, less 10 for each hint used on that pass ("Show me how" counts as one), and never under 10. A repeat gives nothing; time isn't counted. Re-secure bonus: 10 points each time a unit drops and the student brings it back to 100% (one star on the unit), up to 5 stars, so up to 50 points a unit. The Most points board shows secured, level, programme and re-secure bonus points, then the combined total (all four added) as a number only, such as 12,400: it has no limit. Secured and level points give up to 300 a unit (12,000 for 40 units); the % column is the combined total out of that, so it can go past 100%. Most improved still counts only secured and level points. Stars don't change certificates.

    Certificates

    A student earns a certificate for a block of units when every unit in the block has its floor at 100%. Select Print to print one.

    How it works

    A unit's floor is the lowest its secured score can drop to. It starts at 50% and goes up by 10 each time the student brings the unit back to 100%. The date on a certificate is the day the last unit in the block reached that. Once earned, a certificate is kept. Select Print to open one certificate on its own page, ready to print on one A4 landscape sheet.

    In this browser (local mode), certificates are kept in this browser only.

    Homework

    Set a number of tasks for the class to do by a due date. A task counts the first time a student passes it.

    How it works

    Every task type counts, placement questions too. A task counts the first time a student passes it, from when you set the homework to the end of the due date. Each student sees a Homework card on their home page with "x of y done", then "Complete". A paste is flagged when the editor is empty and the paste is 3 lines or more, or when a single paste is more than 8 lines. In homework a flagged task doesn't count, and the student gets a new one. The report lists these flags as "Paste flagged".

    Homework needs backend mode (the class server), because students must be able to see it on their own computers.

    Assignments

    An assignment is a set of tasks for the whole class. Every student sees the open ones at the top of their home page. It is practice only: no score, no effect on their level or progress, unlimited tries, free hints, and "Show me how" on every task. Their work is still recorded, so you can see below what happened.

    Assignments need backend mode (the class server), because students must be able to see them on their own computers.
