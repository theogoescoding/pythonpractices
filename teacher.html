What is kept, and for how long
  • Nicknames, progress and attempts are kept until the class ends (its end date) or is deleted. A student can delete all their own progress from the landing page; you can delete a single student or the whole class here.
  • Program code and output from failed attempts are kept in full for 30 days, then cleared every night. The failure category, misconception matches and a fingerprint of the code stay.
  • Login codes are kept encrypted until the class is deleted or ends. Only you can reveal them (with "Show codes"), and each reveal is logged.
  • PINs are stored only as a one-way hash. No one can see them, not even you.
  • The data is held by Supabase in the EU (Ireland).

Secured score per unit

One row per student, one column per unit for this class's stage. Each cell shows the secured score and its label (or, if the unit isn't secured yet, the level in its colour), the level, the placement result, ★ Complete once a level 10 task is passed, and these flags, with the time of the newest press:

  • Too easy the student pressed "This is too easy" in this unit, which moved them up one level: check that their level is right
  • Way too hard the student pressed "This is way too hard" in this unit, which moved them down one level: check that their level is right
Select a column heading to sort. Select it again to reverse the order. Unit columns sort by secured score. Select a name to open that student.

Colour key: grey: Not placed yet. Placed but not secured yet, the level: Level 1–3 Level 4–6 Level 7–9 Level 10. Secured, how fresh it is: 100% Secured 95% Fresh 80–90% Fading 50–75% Revisit soon (a secured unit never falls below 50%, so it is never red). A unit stays grey until the student has done its placement test. A placed unit that isn't secured yet shows its level in that level's colour, never 0%. A student's average is of their secured units; the summary tiles count each student once, by that average or, with nothing secured yet, by their average level. A unit is secured after two level 10 passes with no hints (a pass after "Show me how" doesn't count). It then drops 5 points a week, never below its floor, and one more level 10 pass with no hints brings it back to 100%.

Assignments

An assignment is a set of tasks for the whole class. Every student sees the open ones at the top of their home page. It is practice only: no score, no effect on their level or progress, unlimited tries, free hints, and "Show me how" on every task. Their work is still recorded, so you can see below what happened.

Assignments need backend mode (the class server), because students must be able to see them on their own computers.
